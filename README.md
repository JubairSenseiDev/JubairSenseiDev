# Overview

Jubair Sensei is a Bangla technology community focused on building high-quality software and delivering practical digital solutions.

We design and develop web applications, mobile apps, Flutter applications, Linux software, Telegram bots, APIs, automation systems, and custom software tailored for businesses, creators, and developers.

Alongside software development, we publish practical tutorials, learning resources, and technical content to help the Bangla tech community grow with modern technologies.
