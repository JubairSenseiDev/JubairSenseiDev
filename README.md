## About

I build **Jubair Sensei** — a Bangla-speaking tech community for learners, builders, and sharers. We cover tutorials, tools, configs, and real talk. Everything under the tech sun is on the table.

> The only thing we don't do: hacking social media accounts. We're not cyber criminals — we're builders, learners, and sharers.
